# Contributing

Thank you for considering a contribution.

## Project context

This is an Unreal Engine Blueprint collaboration scaffold. Do not claim the planned Content directories or a working Unreal project already exist. Configure Git LFS before committing large binary assets.

## Workflow

1. Open an issue before substantial changes.
2. Create a focused feature branch and keep pull requests small.
3. Document setup requirements and manually verify affected features.
4. Include testing notes and screenshots for visual changes.
5. Do not commit credentials, personal data, generated caches or third-party assets without redistribution rights.

## Licensing

No open-source license has been confirmed for this repository. Ask the repository owner about contribution licensing before submitting substantial work.
